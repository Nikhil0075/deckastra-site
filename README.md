# Deckastra site

The public product, documentation, developer, hackathon, and download site for [Deckastra](https://github.com/Nikhil0075/deckastra).

## Development

```bash
npm ci
npm run dev
```

The production site is mounted at `/deckastra-site/`. Run the complete local gate with:

```bash
npm run check
```

Only curated public material belongs in this repository. Local evidence profiles, databases, logs, exports, legal drafts, credentials, and personal identifiers must never be copied here.
