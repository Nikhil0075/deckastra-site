# Review an agent change

1. Open **Draft changes** when the chip indicates pending work.
2. Read the request and attributable source.
3. Open **Review** and compare before/after slides.
4. For motion changes, choose **Play motion**.
5. Approve only when the result and scope match your intent; otherwise reject it with a reason.
6. If Review says the proposal is out of date, reject it and request a fresh proposal.

Every connected-agent change waits here—even a small one. Approval is never delegated to the connected agent.
