# Add and preview motion

1. Open **Motion**.
2. Select an object and choose an entrance, emphasis, loop, or exit behavior—or ask an agent to prepare one.
3. For subtle atmosphere across slides, request ambient motion.
4. Use the timeline to adjust start, duration, and click boundaries.
5. Scrub the playhead or use the slide play control.
6. If the motion is in a pending proposal, open Review and choose **Play motion** before approval.

Respect reduced-motion needs and avoid movement that competes with the speaker’s point.
