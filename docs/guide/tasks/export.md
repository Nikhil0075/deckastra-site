# Export a deck

1. Open **Share → Export**.
2. Choose PDF or PowerPoint.
3. Start the export and wait for completion; long-running work is handled as a job.
4. Read the degradation report before distributing the result.
5. Download the file and inspect representative slides, fonts, pictures, charts, and motion-dependent content.

![Share menu with PDF, PowerPoint, and Deckastra file export choices](/screenshots/30-export-menu.png)

![Export finished with the degradation report listing flattened items](/screenshots/18-export-degradation-report.png)

PowerPoint may flatten features that cannot remain editable. The ledger is the authoritative explanation; a successful download does not imply perfect feature parity.
