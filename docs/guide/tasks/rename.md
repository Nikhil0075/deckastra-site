# Rename a deck

![The deck title selected for editing in the top bar](/screenshots/29-rename-title.png)

In the editor, select the title in the top bar, type the new name, and press Enter. Press Escape to cancel. From **All decks**, open a deck card’s menu and choose **Rename**. The same name appears in the editor and card list after save.
