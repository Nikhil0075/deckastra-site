# Recover work

If the local workspace service stops, keep the editor open and choose **Retry** after it returns. Download the emergency local copy first if the app offers it. Once recovered, wait for **Saved**, inspect version history, and create a backup.

To undo an accepted change, use ordinary Undo where appropriate or restore a chosen version from **Version history**. A restore creates new history rather than erasing the intervening record.
