# Work with templates

1. Open **Templates** from the project home.
2. Filter by purpose or design language.
3. Preview the deck structure, theme, and visual grammar.
4. Choose a template and fill its named content slots.
5. Open the resulting deck and refine text, media, layout, and motion as ordinary structured objects.
6. Use Design Check before presenting or exporting.

![Reviewed template gallery](/screenshots/02-template-gallery.png)

Templates are editable starting points, not flattened backgrounds. A design language can change the composition grammar as well as color and typography.
