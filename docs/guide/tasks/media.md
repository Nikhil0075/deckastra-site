# Add media

1. Open **Import & generate** or the project media library.
2. Upload an existing picture or video, or choose an available governed generation mode.
3. Review provider and credit disclosures before requesting generated media.
4. Add meaningful alternative text.
5. Place the asset in a picture frame, at center, as a background, or as a replacement for an existing picture.
6. Adjust crop and geometry without changing the source asset bytes.

![Media import and generation controls](/screenshots/08-media-library-generation.png)

Connected agents use the controlled media placement workflow so a proposal cannot reference an asset missing from the deck.
