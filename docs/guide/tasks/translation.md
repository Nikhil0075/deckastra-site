# Translate a deck

1. Sign in and confirm credits are available.
2. Open **Import & generate** or the language control.
3. Add the target language and select the slides or text to translate.
4. Review the provider disclosure and submit the translation.
5. Switch the language lens from the top bar and review every slide.
6. Fix missing or outdated entries. Layout changes apply across languages; wording changes apply to the current language.
7. Use **Show original** when comparison is needed.
