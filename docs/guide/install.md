# Install Deckastra

## macOS ARM64

1. Download `Deckastra-0.9.0-beta.1-mac-arm64.dmg` from the [official download page](/download).
2. Verify the published SHA-256 before opening it.
3. Open the disk image and move Deckastra to Applications.
4. Because this beta is unsigned, macOS may block the first launch. Open **System Settings → Privacy & Security**, verify the app and source, and choose the offered approval action.
5. Reopen Deckastra and create the local workspace when prompted.

## Windows x64

The Windows x64 installer is available from the public prerelease. It is unsigned, so:

1. Download `Deckastra-0.9.0-beta.1-win-x64.exe`.
2. Verify SHA-256 `88EBD5978CEDDB18D0084577AAFC42EDF6AD04A6FF1A4AFACC8FA0153148C2CC`.
3. Open the installer. If SmartScreen appears, choose **More info**, verify the source, then **Run anyway**.

![Windows SmartScreen showing the Deckastra installer with Run anyway and Don’t run](/screenshots/31-windows-smartscreen.png)

Internet access is needed for sign-in and cloud-backed features. Core local editing does not require a provider connection. A second display is optional for the presenter console.
