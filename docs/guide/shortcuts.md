# Keyboard shortcuts

On macOS, use Command where the table says Ctrl.

| Keys | Action | Where |
|---|---|---|
| Delete / Backspace | Delete selection | Canvas |
| Ctrl+C / X / V | Copy / cut / paste | Canvas |
| Ctrl+D | Duplicate selection | Canvas |
| Ctrl+A | Select all | Canvas |
| Ctrl+G / Ctrl+Shift+G | Group / ungroup | Canvas |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo | Editor |
| Ctrl+Alt+Z | Undo last AI change | Editor |
| Ctrl+] / Ctrl+[ | Bring forward / send backward | Canvas |
| Ctrl+Shift+] / Ctrl+Shift+[ | Bring to front / send to back | Canvas |
| Arrow keys | Nudge selection | Canvas |
| Enter | Edit selected text | Canvas |
| Ctrl+Shift+P | Present | Editor |
| Ctrl+1…5 | Open Design, Motion, Narration, Code, or Import | Editor |
| Ctrl+Alt+1…5 | Toggle Insert, Slides, Side panel, Notes, or Timeline | Editor |
| F6 / Shift+F6 | Next / previous editor region | Editor |
| Ctrl+K | Command palette | Editor |
| Right / Space / Page Down | Advance reveal | Present mode |
| Left / Page Up | Previous reveal | Present mode |
| Down / Up | Next / previous slide | Present mode |
| B | Toggle black screen | Present mode |
| N | Toggle notes | Present mode |
| P | Toggle presenter console | Present mode |
| 1 / 2 / 3 | Toggle ink tools | Present mode |
| C | Clear current-slide ink | Present mode |

Object shortcuts require canvas focus. Text fields keep native typing and editing behavior.
