# Interface tour

![Deckastra editor with selected object](/screenshots/03-editor-selection.png)

1. **Slide rail** — add, select, reorder, duplicate, and inspect slides.
2. **Insert tools** — add text, shapes, icons, media, charts, tables, diagrams, equations, and code.
3. **Canvas** — select and directly manipulate structured objects.
4. **Modes** — switch among Design, Motion, Narration & sound, Code, and Import & generate.
5. **Inspector** — edit geometry, type, color, object options, and semantic details.
6. **Notes and timeline** — write speaker notes and control reveal or animation timing.
7. **Assistant and Draft changes** — ask for work, inspect pending proposals, and open Review.
8. **Share and Present** — export, rehearse, open the presenter console, and control an audience display.

Press <kbd>F6</kbd> or <kbd>Shift</kbd>+<kbd>F6</kbd> to move between major editor regions without relying on a pointer.
