# Create your first deck

1. From **All decks**, choose **New deck** or open **Templates**.
2. Pick a reviewed template for a complete starting structure, or choose blank for full control.
3. Add slides from the slide rail and insert text, pictures, charts, tables, diagrams, equations, or code.
4. Select an object to edit its geometry and style in the side panel.
5. Open **Design Check** and resolve findings that matter for your intent.
6. Rename the deck from the title in the editor.
7. Choose **Present** to rehearse, then **Share → Export** for PDF or PowerPoint.
