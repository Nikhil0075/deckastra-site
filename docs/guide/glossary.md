# Glossary

**Proposal** — Versioned operations that have not changed the authoritative deck. Every connected-agent change arrives this way and waits for approval.

**Review** — The before/after workspace where a person approves or rejects a proposal and can preview pending motion.

**Draft Board** — The geometry-free planning surface used before draft content becomes a slide proposal.

**Design language** — A reusable system of type, color, spacing, imagery, motion, and composition rules.

**Design Check** — Deterministic findings about layout, contrast, reading order, editability, and related presentation quality.

**`.mydeck`** — Deckastra’s canonical packaged presentation format containing structured document data and referenced resources.

**Degradation report** — The export ledger explaining features a target format flattened, approximated, rasterized, or dropped.

**Agent access** — Explicit, time-bounded local permission allowing an MCP client to read within scope and submit proposals. It does not grant approval or sharing authority.
