# Security and trust boundaries

- Human approval for every connected-agent change.
- Scoped agent grants that expire and can be revoked.
- Revision checks that refuse stale proposals.
- Server-side provider credentials and keyless GitHub deployment to Google Cloud.
- OIDC-backed identity and private object storage.
- Versioned proposal and document history.
- Redacted diagnostics and stable cloud error codes.
- Structured `.mydeck` import validation for paths, sizes, digests, references, and formats.

## Honest limits

This beta is unsigned. Final operator legal documents, broader installed-release testing, formal load and recovery acceptance, alert receipt, and security testing remain publication and production-readiness work. The site does not claim perfect security or perfect export fidelity.
