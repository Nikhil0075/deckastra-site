# Example agent prompts

These examples inspect first, bound the requested change, and leave authority with the person in Deckastra.

![Proposals from Antigravity waiting for review in Deckastra](/screenshots/10-proposal-review.png)

<CopyPrompt title="Create a deck" prompt="In Deckastra, create an eight-slide technical briefing. Use a reviewed template, include one architecture diagram and one editable comparison table, run Design Check, and leave the result as proposals for my review." />

<CopyPrompt title="Improve one slide" prompt="Read the currently open slide and propose a clearer hierarchy without changing its factual wording. Keep the current design language and do not touch other slides." />

<CopyPrompt title="Place media" prompt="List suitable workspace images, inspect the selected asset, and propose it in the current picture frame with meaningful alt text. Do not generate new media." />

<CopyPrompt title="Add motion" prompt="Propose restrained object motion for the current slide using its semantic roles. Keep existing click reveals, prefer measured pacing, and make it available to Review’s Play motion control." />

<CopyPrompt title="Translate" prompt="List the missing Hindi translation slots, preserve numbers, links, and placeholders, and propose translated wording for my review without changing slide geometry." />

<CopyPrompt title="Resolve a stale proposal" prompt="The previous proposal is out of date. Read the current deck again, summarize what changed, and prepare a new proposal without reintroducing edits I made after the first attempt." />

<CopyPrompt title="Export" prompt="Export the approved current deck to PDF and PowerPoint. Wait for each job, report the degradation ledger, and do not claim perfect fidelity where an item was flattened." />
