# Five-minute demo walkthrough

1. **Open Deckastra** — show the project home, local/cloud boundary, and reviewed templates.
2. **Create or open a deck** — choose a technical template and show that the result remains editable.
3. **Rename it** — edit the top-bar title and confirm the card updates.
4. **Edit an object** — move or restyle one element and open structured Code view.
5. **Open an agent proposal** — show the request, attribution, and pending state.
6. **Play proposed motion** — preview the pending timeline before it changes the deck.
7. **Approve or reject** — compare before/after and make the human decision explicit.
8. **Show Hindi translation** — switch to the translated language lens and compare with original.
9. **Open the voice selector** — show the live Hindi voice inventory and timing model.
10. **Export** — run PDF or PowerPoint and read the degradation report.

Keep the story focused: structure, deterministic composition, human authority, and honest output boundaries.
