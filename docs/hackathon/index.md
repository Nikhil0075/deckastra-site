# Hackathon submission overview

<StatusBadge tone="beta">Media, Content & Digital Experiences</StatusBadge>

Deckastra is a submission to [AI Builder Cup](https://aibuildercup.com/) in the Media, Content & Digital Experiences track. It is an AI-native presentation studio built around a strict product thesis: agents propose structured intent, deterministic engines compose, and people approve reviewable changes.

## Problem solved

Presentation automation often trades away editability, review, or trustworthy export. Deckastra keeps every slide as structured objects, routes connected-agent changes through human review, preserves history, and reports export degradations.

## What was built

- Direct desktop and web authoring surfaces.
- A canonical `.mydeck` model and deterministic renderer.
- 50 MCP tools for connected-agent workflows.
- Before/after proposal review with stale-write protection.
- Motion, presenter console, audience ink, languages, voices, and narration.
- PDF and editable PowerPoint export with degradation reports.
- Recovery, version history, backup, privacy, and diagnostic boundaries.
