# Feature directory

## Authoring and design

- Direct canvas editing with text, shapes, icons, pictures, charts, tables, diagrams, equations, and code.
- Reviewed templates, themes, design languages, and reusable style choices.
- Structured code inspection alongside the visual canvas.
- Design Check for overlaps, contrast, reading order, and export editability.
- Media upload, import, library management, and governed generation.

## Assistants and connected agents

- Built-in assistant and geometry-free Draft Board.
- MCP connections for Claude Code, Codex, and compatible clients.
- Scoped agent access that is opt-in, expiring, and revocable.
- Before/after review, pending motion preview, and stale-write protection.

## Motion and delivery

- Object entrances, emphasis, loops, exits, transitions, and click reveals.
- Deterministic timeline editing and reduced-motion fallbacks.
- Presenter console, notes, timer, black screen, audience window, and ink.

## Languages, narration, and export

- Original and translated language lenses sharing one geometry.
- Missing/outdated translation state, live voice inventory, pronunciation mappings, and timed narration.
- PDF and PowerPoint export with a degradation ledger.
- Version history, inverse operations, recovery journal, emergency local copy, backup, and restore.
