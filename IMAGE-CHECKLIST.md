Take each screenshot and save it with its number as the start of the file name, for example `07.png` or `31.png`.
Put all of them in one folder and tell Claude where it is. Claude then renames and places them.

**Size:** full-window 16:9 captures, about 1920×1080. The gallery crops to 16:9, so other shapes lose their edges.
**Format:** PNG works best. JPG is fine for large, photo-heavy screens.
**Theme:** use the same app theme for every shot so the site looks consistent.
